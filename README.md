Customer Shopping Behaviour Analysis

The Customer Shopping Behaviour Analysis project focuses on understanding customer purchasing patterns, shopping preferences, and buying trends using data analysis techniques.
The project helps businesses make data-driven decisions by identifying customer behaviour, popular products, spending habits, and sales insights.

This project was developed using:

Python for data cleaning, preprocessing, and analysis
SQL for querying and managing the dataset
Power BI for creating interactive dashboards and visualizations
-- Objectives--
Analyze customer purchasing behaviour
Identify top-selling products and categories
Understand customer spending patterns
Discover shopping trends and purchase frequency
Generate business insights through dashboards
